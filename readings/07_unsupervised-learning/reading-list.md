# Session 7 readings - Unsupervised learning

## Core

1. **ISLR chapter 12 ("Unsupervised Learning").** <https://www.statlearning.com/>
   PCA and clustering in one chapter, with the R code the `.Rmd` lab builds on.

2. **Wattenberg, Viégas & Johnson, "How to Use t-SNE Effectively", _Distill_, 2016.**
   <https://distill.pub/2016/misread-tsne/>
   Interactive, and the best available inoculation against over-reading a two-dimensional
   embedding. Required before you put any such plot in your project report.

## Optional

3. **Shlens, "A Tutorial on Principal Component Analysis", 2014.**
   <https://arxiv.org/abs/1404.1100>
   PCA derived twice - through the covariance eigen-decomposition and through the SVD. Read
   it if the lecture's geometry felt like assertion rather than argument.
